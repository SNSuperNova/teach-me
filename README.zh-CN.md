# teach-me — 短时互动学习的 AI 教学 Skill

[English](README.md)

**teach-me 是一个 MIT 开源 Agent Skill，通过一次短时、专注的对话，帮助你理解一个概念或掌握一种方法。**它指导 AI 导师讲解、让你尝试、提供反馈，再换个情境检验理解。它聚焦当前主题，不创建课程或长期学习档案。

适合希望自己理解并动手练习，而不只是拿到答案的人。

## 什么情况下适合用 teach-me？

- **理解概念**：用自己的话解释数据库事务，并分析一个具体例子。
- **学习方法**：在提示下练习排查一个小问题，而不是直接获得完整解法。
- **检验推理**：回应反例、为自己的解释辩护，或找出论证中的错误。
- **通过讲解学习**：你来教 AI，让它检查你的理由是否成立。

每次选择一个主题。你可以随时要求重讲、重练、挑战，或者结束。

## 一轮教学如何进行？

**判断起点 → 讲解一个关键点 → 让你尝试 → 提供反馈 → 换个例子检验。**

导师等待你的回答，根据具体误区调整，不把“懂了”、复述原话或猜对当作理解。当你能独立解释关键理由，并应用到有变化的情境时，可以结束本轮；是否继续由你决定。

### 对话示例

*以下为预期交互方式的示意，不是实测对话记录。*

> **你：**帮我理解，转账为什么需要数据库事务？
>
> **导师：**假设付款方扣款成功，但收款方入账失败，会出现什么问题？
>
> **你：**付款方少了钱，收款方却没有收到钱。
>
> **导师：**对。原子性要求这两步一起成功，或者一起回滚。现在换成“扣库存成功，但创建订单失败”，你认为应该怎么处理？为什么？

## teach-me 和 grill-me 有什么区别？

[grill-me](https://github.com/mattpocock/skills) 通过追问帮助你明确计划或决策；**teach-me 通过教学、练习和挑战，检验你是否理解一个主题。**本项目受其聚焦追问方式启发，教学指令为独立编写。

## 安装

它是 Markdown 格式的技能指令，不是独立教学应用。请使用支持 `SKILL.md` 格式的 Agent。以 macOS 或 Linux 上的 Codex 为例：

```sh
git clone https://github.com/SNSuperNova/teach-me.git
mkdir -p ~/.codex/skills/teach-me
cp teach-me/SKILL.md ~/.codex/skills/teach-me/SKILL.md
```

如果设置了自定义 `CODEX_HOME`，使用其中的 `skills/teach-me` 目录。其他 Agent 使用各自支持的技能目录。

默认指令为英文。如需中文指令，将 `SKILL.zh-CN.md` 复制到安装目录并命名为 `SKILL.md`。两个版本采用同一方法，只需安装其中一个。你可以要求用中文或英文教学。

## 使用

```text
用 $teach-me 帮我理解数据库事务。
```

过程中可以说：“换一种解释”“再来一道题”“我来教你”“挑战一下我的推理”。

## 常见问题

**它会记住我上次学到哪里吗？**

Skill 使用当前对话，不创建长期学习档案。它不会改变平台自身的聊天保存、记忆或数据保留设置。

**完成一轮就代表彻底学会了吗？**

它反映你在本轮展示出的理解，不代表已经长期记住。你可以自行选择重复学习或继续练习。

**它只能教编程吗？**

不是。指令不限定学科，适合通过解释、预测或实际任务检验理解的概念和方法。教学质量取决于所用模型和可用资料。
